# target-skill

> 目标追踪 + 抗偏移 — 设定目标后持续对齐，AI跑偏时主动纠正，歧义时让用户拍板

## 核心功能

- **目标锁定** — 设定后持续追踪，每次回复前对齐
- **跑偏检测** — 立即识别偏移，列出对比分析
- **歧义确认** — 不自己猜，让用户选择方向
- **问题拆解** — 达成目标需要解决哪些问题，列好优先级
- **更大目标发现** — 发现更大机会时主动提出，引导用户确认是否切换
- **目标变化日志** — 每次调整记录原因，可回溯

## 触发条件

- 设定目标
- 目标跑偏
- AI跑偏了
- 追踪这个目标
- 帮我保持目标
- 纠正AI方向
- 发现更大目标
- 这个和目标冲突吗
- 目标变化了

## 工作流程

```
用户设定目标
    ↓
拆解问题 + P0/P1/P2 优先级
    ↓
开始执行（每次回复前对齐）
    ↓
检测偏移 → 列出冲突 → 用户选择
    ↓
发现更大目标 → 引导确认
    ↓
目标达成 / 放弃 / 切换
```
