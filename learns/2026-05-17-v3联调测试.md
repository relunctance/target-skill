## Rollback + 质量门禁真实触发测试（第五次，2026-05-17）

### Rollback 测试

**场景**：M1-2 执行时遇到 AttributeError，触发 Rollback

**流程**：
1. M1-1 done → M1-2 执行失败（AttributeError）
2. Rollback → M1-2 pending，M1-3~M1-5 pending
3. 用户选择「重试 M1-2」
4. 修复 import 路径 → M1-2 done
5. 继续 M1-3, M1-4, M1-5

**验证结果**：✅ Rollback SOP 可用

### 质量门禁测试

**场景**：M1-5 完成后触发质量门禁

**流程**：
1. M1-5 done → 质量门禁检查
2. 第一次：ruff 3 errors + pytest 1 failure → 🔴 blocked
3. 修复问题 → 重新检查
4. 第二次：ruff 0 errors + pytest 0 failures → ✅ 通过

**验证结果**：✅ 质量门禁 SOP 可用

### 关键发现

1. Rollback 后，subTask N+1 的状态也需要回滚（本测试中 M1-3~M1-5 回滚）
2. 质量门禁失败时 milestone 状态设为 blocked
3. 修复后说「重新检查质量门禁」继续流程
